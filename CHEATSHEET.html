Autism A&P Builder — Cheat Sheet

One-page reference. Pin it next to your monitor.

Order of operations

  • 1. Pick Diagnosis Status (banner) — nothing renders without this
  • 2. Pick Visit Type
  • 3. Fill Section 1 — age, pronouns, language, cognitive, adaptive
  • 4. If confirming: check DSM-5 criteria (Section 3) and pick severity levels SC and RRB (Section 2)
  • 5. Click functional needs in Section 4
  • 6. Set School documentation status (Section 6) if you want the IEP letter
  • 7. Review the right panel — A&P, ABA, IEP tabs
  • 8. Copy → paste into Epic / Word

Why a tab is hidden

TabHidden when…
ABA LetterDiagnosis status is not "Confirmed"
IEP LetterAge group is toddler, OR school documentation status is unset
A&P NoteNever — always visible (may say "select a diagnosis status")
If a tab you expect is missing, scroll up to check the Diagnosis Status banner and the School section.

Copy buttons — when to use which

  • Copy Rich Text — for Epic note composer or Word; preserves bold and structure
  • Copy Plain Text — for systems that don't render formatting; monospaced with dividers
  • Copy for Epic (***) — replaces every {placeholder} with *** so you can Tab through them in Epic

Auto-logic — what to expect

Auto-suggestions show a blue AUTO badge. You can always uncheck or override in Section 7.

Dots and badges in section headers

  • Green dot — section has content filled in
  • Gray dot — section is empty
  • Tap the dot (mobile) — does NOT collapse the section (safe tap target on the sticky header)
  • Tap the section header — collapses or expands the section (animated on mobile)
  • Amber outlined section — diagnosis status is "Suspected" and this section is contextually highlighted

Trauma — disclosure to school

  • Checking "Trauma" in Section 5 puts it in the A&P note (medical chart) by default
  • It does NOT appear in the IEP letter unless you also check the sub-checkbox "Include in IEP letter"
  • When included, the letter uses functional language — no ICD-10 code, no word "trauma"
  • A reminder banner appears above the letter to confirm family consent
If unsure whether the family has consented to share with school, leave the sub-checkbox off.

SLD (learning disability) handling

  • If you pick a confirmed-domain SLD (reading, math, written): "suspected" is automatically cleared
  • If you pick "suspected": all confirmed-domain SLDs are cleared
  • Multiple confirmed domains may coexist (e.g., reading + math)
  • "Suspected" stays domain-uncharacterized — the letter recommends the school evaluation determine which domain

Severity levels (SC vs RRB)

  • Pick separately for Social Communication (SC) and Restricted & Repetitive Behaviors (RRB)
  • Both default to nothing — you must pick
  • The tool uses max(SC, RRB) for IEP and ABA letter severity, so the highest support need across either domain drives those letters
  • The A&P note displays both levels separately

Before sending the IEP letter

  • Fill in every {placeholder} — student name, date, school name, principal name, your name and phone
  • Review the timeline language — verify it reflects current Florida ESE rules
  • Review eligibility-category phrasing — letter recommends, IEP team decides
  • Confirm any trauma reference is family-authorized for school disclosure
  • Read the full letter top to bottom one time — copy is not a substitute for review
See LIMITATIONS.md for the review steps the clinician still owns (placeholders, state-specific phrasing for non-Florida districts, full read-through).

If something looks wrong

  • Section 7 — Adjust referrals (Auto / Include / Exclude per therapy)
  • Section 5 — Toggle "Include plan" pill to add/remove comorbidity plan blocks
  • Clear All button (top right, red) — wipes everything, confirms first
  • Mobile: use the Input / View Note nav at the top to switch panels
  • Closing the tab loses all inputs — no auto-save by design (no PHI stored)
